# Debate Transcripts

Machine-written by the debate orchestration; humans read, never edit. One
file per debate: `YYYY-MM-DD-<slug>.md`, with frontmatter recording the
question, participating engines and role assignments per rotation (after
ROUTING.md pruning), rounds, the reported outcome state, concessions
(reasoned vs. capitulation), and the IDs of every claim registered to
`evals/ledger.yaml` and every dispute opened in `DISPUTES.md`.

# R-ACCEPT-001: Reflexive Acceptance Criterion

Statement: Portfolio returns are rejected as the demo's success metric
(single-period returns are luck-confounded). The demo is accepted when
(a) the human user is happy, and (b) the engines, in a rotated debate whose
evidence is this repository's own usage records — resolved evals-ledger
predictions, disputes settled by observables, kill/profit criteria that
fired before outcomes, capitulations caught — converge that the setup is an
acceptable way to help real users gain knowledge about the positions they
hold. The acceptance debate may not be convened before at least two months
of live usage crossing at least one earnings season, during which the shared
knowledge on positions is updated against the market's evolution. Because
the debate is human-triggered (an unhappy owner never convenes it), its
function is to veto false satisfaction; it must argue only from scoreable
records, never from impressions of transcript quality, and its converged
claim is worded honestly as "this helped this user" (n=1), with plural users
as the extrapolation argued for.
